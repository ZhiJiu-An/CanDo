# 个人厨房小程序 MVP 文档

## 一、项目概述

**项目名称**：个人厨房（CanDo）

**定位**：一个个人菜谱记录与浏览小程序，用户可以把自己会做的菜上传存档，包含菜品封面图、食材清单和纯文字制作步骤，方便随时查阅和复现。

**目标**：以最小可行产品（MVP）快速跑通"记录—浏览"核心闭环，验证使用体验后再迭代进阶功能。

**当前状态**：✅ MVP 核心功能与首批扩展功能（搜索 / 自定义分类 / 收藏置顶标签）均已开发完成，云函数已部署至云端环境并通过真机验证。

## 三、页面规划

### 页面 1：首页（菜品列表）
- 顶部分类筛选 Tab（全部 + 云端动态分类）
- 网格卡片列表：每张卡显示封面图、菜名、标签（最多 2 个），置顶菜品优先
- 右下角悬浮「+」按钮 → 进入新增菜品页
- 点击卡片 → 进入菜品详情页
- 顶部搜索入口 → 进入搜索页；「我的」页内可进入分类管理

### 页面 2：新增 / 编辑菜品页
- 表单字段：
  - 菜名（必填）
  - 封面图（必填，拍照/相册）
  - 分类（必选，云端分类列表）
  - 简介（选填，多行文本）
- 食材清单区块：动态行（食材名 + 用量），可增加/删除行
- 制作步骤区块：动态步骤项（纯文字），可增加/删除、上移/下移调整顺序
- 底部「保存」按钮

### 页面 3：菜品详情页
- 顶部封面图、菜名、分类标签、简介
- 食材清单列表
- 制作步骤（有序列表，序号 1/2/3…）
- 标签区：点击已有标签删除，可输入新增标签
- 收藏 / 置顶快捷操作
- 右上角「编辑」「删除」入口

### 页面 4：搜索页
- 搜索输入框（实时/触发式搜索）
- 匹配范围：菜名、简介、食材、标签（模糊匹配，大小写不敏感）
- 结果以菜品卡片列表展示

### 页面 5：分类管理页
- 分类列表：名称 + 菜品数量，系统分类带标识
- 新增分类、重命名（非系统分类）、删除（非系统分类，菜品自动迁移至「其他」）

### 页面 6：我的页
- 入口聚合：分类管理、搜索等
- 数据统计（菜品总数等）

## 四、数据模型设计

### dishes 集合（菜品）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| _id | string | 是 | 菜品 ID（自动生成） |
| _openid | string | 否 | 创建者 openid（云开发自动写入） |
| name | string | 是 | 菜名 |
| coverImage | string | 是 | 封面图云存储 fileID |
| category | string | 是 | 分类名称 |
| intro | string | 否 | 简介 |
| ingredients | array | 否 | 食材清单 |
| steps | array | 否 | 制作步骤（纯文字） |
| favorited | boolean | 是 | 是否收藏 |
| pinned | boolean | 是 | 是否置顶 |
| tags | string[] | 是 | 标签列表 |
| createdAt | date | 是 | 创建时间 |
| updatedAt | date | 是 | 更新时间 |

### ingredients 子结构
```json
{ "name": "番茄", "amount": "2个" }
```

### steps 子结构
```json
{ "order": 1, "text": "番茄切块，鸡蛋打散。" }
```

### categories 集合（分类）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| _id | string | 是 | 分类 ID（自动生成） |
| name | string | 是 | 分类名称（唯一） |
| system | boolean | 是 | 是否系统分类（「其他」为兜底分类，不可删改） |
| createdAt | date | 是 | 创建时间 |

> 集合为空时 `getCategories` 云函数会自动播种默认分类（家常菜/汤品/主食/小吃/其他）。

## 五、技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Taro 4 + React 18 | 跨端能力，一次开发多端运行 |
| 状态管理 | Zustand | 轻量全局 store，保证新增/编辑/删除后列表实时同步 |
| 数据存储 | 微信云开发 - 云数据库 | 免后端，菜品与分类数据存储 |
| 图片存储 | 微信云开发 - 云存储 | 封面图上传托管 |
| 云函数 | wx-server-sdk × 11 | 业务逻辑收口在管理端，绕过前端数据库权限限制 |
| 语言 | TypeScript | 类型安全，维护性好 |

### 云函数清单

| 云函数 | 职责 |
| --- | --- |
| getDishes / getDish | 查询菜品列表 / 详情 |
| createDish / updateDish | 新增 / 整体更新菜品 |
| patchDish | 局部更新（收藏 / 置顶 / 标签） |
| deleteDish | 删除菜品 |
| searchDishes | 服务端模糊搜索 |
| getCategories | 分类列表（含数量统计、空集合自动播种） |
| addCategory / renameCategory / deleteCategory | 分类新增 / 重命名 / 删除 |

> 统一返回格式 `{ code, message, data }`；云函数错误信息取 `err.errMsg`（微信 SDK 错误对象）。
> 部署：`node scripts/deploy-functions.js`（通过微信开发者工具 CLI，需开启服务端口）。
